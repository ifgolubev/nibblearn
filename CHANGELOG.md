# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/) and versions follow [Semantic Versioning](https://semver.org/). Package-level changelogs are generated by Changesets in `packages/*/CHANGELOG.md`.

## [Unreleased]

### Fixed (isolated stylesheet)

- `styles.isolated.css` now also covers properties Nibblearn does not set itself: inside a block they fall back to the browser default instead of the page's value (`all: revert` at the lowest specificity of the stylesheet). Page rules such as `.reader a { font-weight: 700 }`, `.reader img { object-fit: contain }` or `.editor code { border: … }` no longer show through. The block root, elements with a class of your own and SVG are left alone.
- Base reset (both stylesheets): links inherit font weight, paragraphs and `code` inherit line height, `code` has no border, images use `object-fit: fill`, headings are `position: static`.
- Images with `width` and `height` state their aspect ratio as a style too, so the reserved space survives stylesheets that reset attribute hints.

### Added (embedding in styled pages, leaner forms)

- `@nibblearn/react` and `@nibblearn/embed`: `styles.isolated.css`, the regular stylesheet with every rule raised by one id of specificity. Article and rich-text styles of the host page (`.prose p`, `.content h3`, global `button` rules) no longer override Nibblearn's; a Shadow DOM is not needed. Token definitions keep their specificity, so themes work unchanged.
- Base reset: `.nb-root` resets inherited typography (letter spacing, text transform, alignment, indent, font style and weight), and tables, definition lists, list items, labels, images and videos get neutral defaults. The default look is unchanged.
- `@nibblearn/editor`: `ModuleForm` / `ModuleEditor` props `hideFields` (dot paths, `*` for a list index) and `hideIds`.
- `@nibblearn/core`: `unusedFields` in a module definition marks top-level fields the module ignores as hidden in generated forms. Callout, accordion, tabs, carousel and columns no longer show Feedback and Scoring.

### Added (host-graded quizzes)

- `choice-challenge`: `behavior.evaluation: "external"` (no correct options in the config, answers collected and handed over once through `onSubmit` / `details.responses`), and a read-only `review` view of a graded attempt from host data. Locally checked quizzes now report `details.responses` and `records[].selected`.
- `flashcards`: optional `explanation` on the back of a card; `details.reviewedCards` and `details.masteredCards` on completion.
- `NibblearnProvider`: `completion` (`"card"`, `"hidden"` or a render function) hides or replaces the completion card of every module.

### Added (story cards)

- `story-cards`: optional per-card `video` (self-hosted, native controls, captions track), `mediaPosition` (`top`, `bottom`, `left`, `right`), `imageFit`, `align` (`left`, `center`, `right`) and an `action` link button. All fields are optional; existing lesson JSON is unchanged.
- `@nibblearn/core`: `videoSchema`, `videoSrcSchema`, `linkHrefSchema`, `isSafeVideoSrc` and JSON Schema patterns for both. `@nibblearn/react`: `SafeVideo` primitive.

### Added

- `@nibblearn/core`: Zod schemas for 22 module types and the lesson schema, `defineLesson` / `validateLesson` with human-readable errors, evaluation logic, safe formula parser, progress scoring, SSR-safe localStorage adapter, English UI messages with override/translation support.
- `@nibblearn/react`: 22 interactive learning modules (Story Cards, Flashcards, Choice Challenge, True/False, Match the Pairs, Sequence Builder, Category Sort, Fill in the Blanks, Word Builder, Estimation Challenge, Label the Diagram, Spot the Mistake, Hotspot Explorer, Screenshot Walkthrough, Process Explorer, Before / After, Branching Scenario, Simulated Conversation, Priority Matrix, Inbox Triage, What-If Simulator, Budget Allocator), the `LessonPlayer`, `NibblearnProvider`, module registry with custom-module support, shared primitives and a self-contained stylesheet with light and dark themes.
- Showcase website with gallery, module pages, JSON playground, lesson playground, four complete example lessons and documentation.
