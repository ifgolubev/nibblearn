# Nibblearn Storybook

Isolated demos of every Nibblearn module, the Lesson Player and the shared primitives.

- **Toolbar:** switch the **theme** (light / dark) and **reduced motion**.
- **Actions panel:** `onComplete` and `onEvent` calls are logged so you can inspect results and analytics events.
- **Accessibility panel:** every story is checked with axe.

Module stories use the same JSON configurations as the showcase site (`examples/src/modules`).
For the JSON schema of each module see `docs/schema-reference.md`.
