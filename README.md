<h1 align="center">Nibblearn</h1>
<p align="center"><strong>Tiny interactions. Real learning.</strong></p>
<p align="center">
  Beautiful, accessible, interactive learning modules for React — driven by JSON or components.<br/>
  <em>shadcn/ui meets Duolingo, Quizlet, 7taps and Typeform — purpose-built for interactive learning.</em>
</p>

> **Status:** release candidate, not yet published to npm. See [Naming](#naming) for the pre-release name checks.

Nibblearn is an open-source library of **22 interactive learning modules** plus a **Lesson Player** that turns an ordered list of modules into a complete learning experience with progress, scoring, persistence and completion. Every module is a real React component with a strict, documented JSON schema, so lessons can be written by hand, generated by an LLM, or composed in code.

## Highlights

- **22 modules, one design system** — Story Cards, Flashcards, Choice Challenge, True/False, Match the Pairs, Sequence Builder, Category Sort, Fill in the Blanks, Word Builder, Estimation Challenge, Label the Diagram, Spot the Mistake, Hotspot Explorer, Screenshot Walkthrough, Process Explorer, Before / After, Branching Scenario, Simulated Conversation, Priority Matrix, Inbox Triage, What-If Simulator, Budget Allocator.
- **Lesson Player** — intro, animated transitions, progress, previous/next, optional scoring and gamification, local progress persistence with resume, review mode, completion callbacks.
- **AI-native content** — every module is a Zod schema; `validateLesson()` returns human-readable errors with exact JSON paths. A ready-made prompt turns a training document into a lesson.
- **Accessible by default** — keyboard alternatives for every drag and swipe, live announcements, visible focus, reduced motion, WCAG 2.2 AA targets.
- **Themeable** — light and dark themes, CSS variables for accent, radius, fonts, shadows and motion. No Tailwind required.
- **Lightweight & portable** — ESM + CJS, TypeScript declarations, one stylesheet, SSR-safe imports, React 18 and 19, works in Vite and Next.js.
- **Private by design** — progress stays in the browser unless you provide a storage adapter. No analytics are collected.

## Quick start

```bash
npm install @nibblearn/react
```

```tsx
import { LessonPlayer, defineLesson } from "@nibblearn/react";
import "@nibblearn/react/styles.css";

const lesson = defineLesson({
  schemaVersion: 1,
  id: "marketing-basics",
  title: "Marketing Basics",
  modules: [
    {
      id: "intro",
      type: "story-cards",
      content: { cards: [{ title: "Welcome!", body: "Let's learn the fundamentals." }] },
    },
    {
      id: "metrics",
      type: "flashcards",
      content: { cards: [{ front: "CTR", back: "Click-through rate: clicks ÷ impressions." }] },
    },
  ],
});

export default function App() {
  return <LessonPlayer lesson={lesson} onEvent={(event) => console.log(event)} />;
}
```

Or use a single module directly:

```tsx
import { Flashcards, flashcardsSchema } from "@nibblearn/react";

const config = flashcardsSchema.parse({
  id: "deck",
  type: "flashcards",
  content: { cards: [{ front: "ROAS", back: "Revenue ÷ ad spend" }] },
});

<Flashcards config={config} onComplete={(result) => console.log(result.score)} />;
```

## The modules

| Category | Module                     | What the learner does                                                                |
| -------- | -------------------------- | ------------------------------------------------------------------------------------ |
| Learn    | **Story Cards**            | Reads bite-sized cards with progressive reveal, expandable notes and embedded checks |
| Learn    | **Flashcards**             | Flips cards, sorts "Got it" / "Practice again", reviews until mastered               |
| Practice | **Choice Challenge**       | Answers single / multiple choice with explanations, partial credit, retries          |
| Practice | **True / False**           | Rapid decisions by button or swipe, with instant explanations                        |
| Practice | **Match the Pairs**        | Taps or drags to connect terms and definitions, in rounds                            |
| Practice | **Sequence Builder**       | Reorders steps by drag or buttons, checks and sees the solution                      |
| Practice | **Category Sort**          | Sorts items into categories by drag or tap-to-assign                                 |
| Practice | **Fill in the Blanks**     | Completes sentences from a word bank or by typing                                    |
| Practice | **Spot the Mistake**       | Finds errors in a mock document or screenshot with hints                             |
| Practice | **Estimation Challenge**   | Estimates a number on a scale, then sees the true answer animate in beside the guess |
| Practice | **Label the Diagram**      | Drags or taps labels onto numbered zones on an image, then checks and retries        |
| Practice | **Word Builder**           | Taps word tiles into order to build a sentence or formula, with per-tile feedback    |
| Explore  | **Hotspot Explorer**       | Explores an image through numbered hotspots with info panels                         |
| Explore  | **Screenshot Walkthrough** | Follows click / type / observe steps over product screenshots                        |
| Explore  | **Process Explorer**       | Clicks through a workflow stepper with details, dependencies and branches            |
| Explore  | **Before / After**         | Drags a divider across two images, reads notes on what changed, answers a check      |
| Decide   | **Branching Scenario**     | Makes decisions with consequences, feedback, points and multiple endings             |
| Decide   | **Simulated Conversation** | Replies in a chat, gets tone / effectiveness coaching and a summary                  |
| Decide   | **Priority Matrix**        | Drags or taps tasks onto a 2×2 matrix (urgent × important), then compares to experts |
| Decide   | **Inbox Triage**           | Works through a realistic inbox: reply, delegate, schedule, archive or report        |
| Simulate | **What-If Simulator**      | Moves sliders and watches metrics, insights and a challenge respond live             |
| Simulate | **Budget Allocator**       | Splits a budget across channels with diminishing returns, then compares to optimum   |

Every module supports typed configuration, hints and explanations where relevant, correct/incorrect or completion feedback, reset and retry, responsive layouts, light/dark themes, keyboard operation, screen-reader announcements, reduced motion, a completion callback and event tracking.

## Design

The default theme is calm and neutral: zinc surfaces, a single **indigo-blue** accent, a warm **amber** highlight for celebrations and a near-black dark mode. Titles and big numbers use a friendly grotesque display face (Bricolage Grotesque — load it yourself, see [Theming](docs/theming.md)). Everything is a CSS variable: change the accent, switch titles to uppercase with `--nb-title-transform`, or square the pill buttons with `--nb-btn-radius`.

## Compatibility and size

- **React 18.2+ and 19**, verified by server-rendering and hydrating every module in StrictMode on both versions. Works with Vite and Next.js (client components); imports are SSR-safe and render deterministically, so there are no hydration mismatches.
- **ESM and CommonJS** builds with TypeScript declarations for both (`publint` and `are-the-types-wrong` clean).
- **Tree-shakeable.** Importing one module does not pull in the others.

Approximate production bundle cost on top of React (minified + gzip, Vite 8):

| You import                         | Added JS | CSS                                   |
| ---------------------------------- | -------- | ------------------------------------- |
| One module (e.g. `TrueFalse`)      | ~105 kB  | 29 kB (one stylesheet for everything) |
| `LessonPlayer` with all 22 modules | ~182 kB  | 29 kB                                 |

Most of the single-module cost is shared runtime: the animation library (Motion) and schema validation (Zod), which your app may already include.

## Naming

Packages are published as `@nibblearn/react` (components and Lesson Player) and `@nibblearn/core` (engine, schemas, validation and types). Checks done on 2026-11-08, before any registration:

| Check                                                           | Result                                                                         |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| npm packages `@nibblearn/react`, `@nibblearn/core`, `nibblearn` | not published (404)                                                            |
| npm organisation `nibblearn`                                    | does not exist                                                                 |
| npm user `nibblearn`                                            | cannot be verified without logging in; confirm while creating the organisation |
| GitHub user / organisation `nibblearn`                          | free                                                                           |
| Domain `nibblearn.com`                                          | not registered                                                                 |
| Trademark search for "Nibblearn"                                | no filings found                                                               |

Related names to be aware of: [Nibble](https://nibble-app.com/), a microlearning app with a pending US trademark application for "NIBBLE: YOUR BITE OF KNOWLEDGE" (interactive lessons and quizzes), and a small unrelated GitHub repository `hhhhuichen/nibblearn`. If the `@nibblearn` scope turns out to be unavailable, the fallback scopes are `@learnzzle` and `@nimblearn` (both currently unused on npm and GitHub). See [docs/release.md](docs/release.md#6-naming-note).
