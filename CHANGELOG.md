# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/) and versions follow [Semantic Versioning](https://semver.org/). Package-level changelogs are generated by Changesets in `packages/*/CHANGELOG.md`.

## [Unreleased]

### Added

- `@nibblearn/core`: Zod schemas for 22 module types and the lesson schema, `defineLesson` / `validateLesson` with human-readable errors, evaluation logic, safe formula parser, progress scoring, SSR-safe localStorage adapter, English UI messages with override/translation support.
- `@nibblearn/react`: 22 interactive learning modules (Story Cards, Flashcards, Choice Challenge, True/False, Match the Pairs, Sequence Builder, Category Sort, Fill in the Blanks, Word Builder, Estimation Challenge, Label the Diagram, Spot the Mistake, Hotspot Explorer, Screenshot Walkthrough, Process Explorer, Before / After, Branching Scenario, Simulated Conversation, Priority Matrix, Inbox Triage, What-If Simulator, Budget Allocator), the `LessonPlayer`, `NibblearnProvider`, module registry with custom-module support, shared primitives and a self-contained stylesheet with light and dark themes.
- Showcase website with gallery, module pages, JSON playground, lesson playground, four complete example lessons and documentation.
